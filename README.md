Descripción

Este repositorio contiene ejemplos en Java sobre las relaciones entre clases, desarrollados como parte de la asignatura Lenguaje de Programación I.

Objetivo

Comprender las relaciones entre clases en Java mediante ejemplos de código y diagramas que permitan identificar sus características.

Temas del trabajo
Herencia y diagrama de clases.
Diferencias entre clase abstracta e interfaz.
Ejemplo de dependencia.
Ejemplo de asociación muchos a muchos.
Ejemplo de interfaz.
Contenido

En este repositorio se organizarán los archivos de código fuente en Java correspondientes a cada ejemplo.

El documento final en PDF incluirá las explicaciones, los ejemplos, el diagrama de herencia y el enlace a este repositorio.
